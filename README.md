# Go Up Office Furniture Website

Static Arabic RTL website for Go Up. Open `index.html` locally or deploy this folder to Netlify.

## Included
- Product catalogue with category filters, instant search, lightbox and quotation cart.
- WhatsApp quote/order and measurement-request actions configured for `https://wa.me/201112269947`.
- About Company text based on the supplied company profile image.
- Combined catalog PDF plus both original PDF parts in `assets/catalog/`.
- Scanned catalog pages in `assets/catalog/pages/`; product cards use a relevant page from their catalog section instead of unrelated stock photography.

## Important catalog note
The source PDFs are scanned catalog pages. OCR and the pre-existing product database do not conclusively verify every model code in the catalog. The website preserves the existing product entries and displays relevant source-page imagery, but the model list should be manually checked against every scanned page before claiming 100% extraction.

## Deploy to Netlify
Drag this folder into Netlify Drop, or connect the repository containing these files. No build command is required.
